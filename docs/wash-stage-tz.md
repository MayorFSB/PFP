# ТЗ: этап мойки (фаза 2)

Стадия `PHASE.wash = [0.32, 0.44]` — «Мытьё». Сюжетно: смываем грязь этапа 1,
волосы становятся влажными и прямыми, готовим к стрижке (фаза 3).
Драйвер: `static/3d/phases/phase2.js`. Активна: `ACTIVE_PHASES` в `config.js`.

## 1. Подокна (доли q внутри стадии, q = (p − 0.32) / 0.12)

| Что | Окно q | Глобалка (факт) | Статус |
|---|---|---|---|
| Влажные + прямые (`uStraight`, wet-блеск) | 0–100% | `TL.straightOn [0.22, 0.31]` | ✅ работает |
| Смыв грязи (`uDirt → 0`) | 0–100% | gate `washFx[0]→washFx[2]` в phase2 | ✅ работает |
| Пузыри по бокам | 30–100% | `TL.washFx [0.27, 0.32, 0.40, 0.46]` | ✅ работает |
| Вода в волосах (капли + 28% стекающих) | 20–100% | тот же `washVis` | ✅ работает |
| Стекающая пена (хлопья на прядях) | 40–100% | тот же `washVis` | ⚠️ общий гейт, своего нет |
| Пар фоном (слабый, ×0.35) | 50–100% | `washVis * 0.35 → uSteam` | ⚠️ общий гейт, своего нет |

## 2. Владение (кто что пишет, конфликтов нет — порядок фаз 0…6)

- `uStraight` — только phase2 (`straightOn` вкл, `straightOff [0.57, 0.63]` выкл).
- `uWash` у `bubbles / water / foamRivulet` (`washLayers()`) — только phase2.
- `uSteam` — ОБЩИЙ: только `max()`-вклады, обнуляет `resetShared()` в `director.js`.
- `uDirt` — пишет phase1 (=1 залипшим), phase2 домножает на `(1 − clean)`, т.к. идёт позже.
- Мокрый вид нитей — шейдер `hair.js`: `vSpec *= 1 − wet*0.55`, `wet = wash`
  (окно `TL.washHair [0.29, 0.38, 0.40, 0.50]` — НЕ путать с `washFx`:
  волосы и частицы идут по разным сеткам сознательно).

## 3. Визуальные требования

1. **Мокрые прямые**: завивка/ветвление схлопнуты (`turns × (1−uStraight)`),
   тон темнее и холоднее (мокрый волос), блик уже и ярче (wet уменьшает
   diffuse-часть `vSpec`, R-лепесток остаётся).
2. **Пузыри**: только по бокам от пучка, не пересекают волосы
   (`halfW 0.41–0.62 + отступ`, две лопасти по `side`). 270 шт, 3 типа
   (классика с радугой / молочная бусина / капля-линза, тип из `fract(aDrop.x*3)`).
   Макс. размер — от ширины экрана: на 1920px большой 75px, малый 23px
   (`director.syncResolution`, целочисленная математика, `?pfp_bubblesize`
   как множитель). Дыхание размера, иридисцентный ободок + каустика.
3. **Вода**: в объёме волос, сверху гуще (`pow(u, 2.4)`), 28% капель стекают
   вниз по пряди (`isDrip`, скорость от `aDrop.w`). Только передняя полусфера.
4. **Пена**: хлопья-облака на прядях (10–30 частиц с кольцами внутри),
   появляются с 40% (сейчас — с общим гейтом; свой сдвиг — доработка §5).
5. **Пар**: слабый фон, переиспользуется на укладке (там сильный).
   Холодная цветокоррекция на окно мытья (`applyGrade`, якорь `GRADE_COOL`).

## 4. Sizing-правила (мировые единицы → px через `pxPerUnit`)

- Пузыри: `uSize` от ширины (п.3.2). Вода/пена: фиксированные
  (`pfp_watersize`, пена 0.16) — их много, скейл не нужен.
- `uViewportH` обновляется в `syncResolution` всем `sizedLayers()` + `syncGumSize`.

## 5. Доработки (не сделано)

1. Свои подокна пене (40%) и пару (50%) — сейчас делят общий `washVis`.
   Нужно: `foamVis`, `steamWashVis` со сдвигом старта.
2. `uStraight` держит `taper × 0.46` — проверить ширину мокрого пучка
   (мокрые слипаются плотнее; возможно, сузить `uWidthK` на окне мытья).
3. Shed-пряди этапа 1 остаются выпавшими — честно, но проверить вид:
   проплешины vs редкость на мокрых.
4. Жвачка отключена (`phase1.js` один строкой назад) — если вернётся,
   решить: смывается пеной или снимается стрижкой.

## 6. Перф-бюджет

300 нитей · 33.6k tris; частицы мытья масштабируются governor (`setStrands`,
`drawn/MAX_STRANDS`); DPR-лесенка 1.0–2.0. В статике (`particles-off`)
пересчёт только по скроллу.

## 8. Референс «душ» (проточная вода) — план

Разбор фото: мокрый локон под струёй. Вода идёт СВЕРХУ ВНИЗ ВДОЛЬ волос
(потоки, а не висячие бусины); капли сидят НА прядях в объёме; брызги-мист
вокруг; волос тёмный мокрый с контрастной глянцевой дорожкой; фон тёмный.

Что реализовать (по приоритету):

1. **Струи** (новый слой, ~150): тонкие вертикальные полупрозрачные нити
   ВНУТРИ массы пучка (не сбоку), медленное стекание вниз, альфа 0.18–0.40.
   Эллипс-спрайт вытянут по волосу. ✅ `streams` в `particles.js`.
2. **Стекающие капли** (доработка water): `isDrip` 28% → 55%, капли вытянуть
   по вертикали, размер ×1.3 на передних, яркий белый блик-точка.
   ✅ `waterFrag`/`water` в `particles.js` (форма через `vLife`).
3. **Мист** (новый слой, ~300): крошечные 3–6px, альфа ~0.15, медленный дрейф
   вокруг пучка — взвесь брызг. ✅ `mist` в `particles.js`.
4. **Мокрый глянец волос** (hair.js): `base × (1 − wet*0.35)` (потемнение) +
   `specR × (1 + wet*0.8)` (узкий яркий блик мокрой пряди).
5. Пузыри/пена/пар — уже есть, не трогать.

Приёмка «душ»: скрин рядом с фото — потоки вдоль прядей, бусины на нитях,
тёмные мокрые + глянцевая дорожка, 0 ошибок консоли.

## 7. Приёмка (базовая)

- `uStraight`: 0 до p=0.22 → 1 к p=0.31; `uDirt`: 1 → 0 к p=0.40.
- Скриншоты статики: p≈0.34 (пена лезет, грязь 0.4), p≈0.37 (чистые прямые).
- 0 ошибок консоли, шейдеры собираются, PHASE непрерывна (лог `[lock]`).
- Эталон стадии 0 не тронут: ниже q=0 все uniform'ы фазы = 0.
